# Zotero Puls

Zotero Puls 是一款面向文献整理与探索的 Zotero 插件，提供作者—标签关系网、分类论文计数、阅读状态、AI 英文标签建议、PDF 选区翻译和 EasyScholar 期刊信息查询。

## 安装

1. 从 [GitHub Releases](https://github.com/mlfc0422/zotero-puls/releases) 下载最新版 `zotero-puls.xpi`。
2. 在 Zotero 中打开“工具 → 插件”。
3. 将 XPI 文件拖入插件窗口并确认安装。
4. 完全重启 Zotero。

当前插件支持 Zotero 7–10.0.*。

如果 Zotero 10 将旧版本标记为“不兼容”，请安装最新 XPI 并完全重启 Zotero；旧版本的清单只声明支持到 Zotero 9。

## 作者—标签关系网

1. 在 Zotero 左侧选择一个普通分类。
2. 点击文献列表工具栏中的“关系网”按钮。
3. 使用节点搜索、最小关系权重和力平衡滑块浏览图谱。

图谱仅读取当前分类中的直接普通条目，不递归读取子分类，并排除附件、笔记和订阅源条目。每篇论文使用第一作者和手动添加的 Zotero 标签；自动标签不纳入图谱。

- 拖动节点可调整布局，其他节点会实时响应。
- 缩放或拖动空白区域可浏览图谱。
- 点击节点可高亮一跳关系并查看关联论文。
- 双击论文可返回 Zotero 并定位原条目。
- 单击空白处取消选择，双击空白处刷新当前分类。
- 关系权重表示同一作者—标签组合由多少篇论文共同支持。

## 分类论文数量

左侧普通分类名称后会显示该分类直接包含的论文数量。计数不包含附件、笔记和子分类中的论文；创建或删除分类、将论文加入或移出分类后会自动更新。

## 阅读状态

在 PDF 阅读器顶部可点击“标记已读”。标记后按钮会显示已读时间（精确时间可悬停查看）和累计有效阅读时长；再次点击可恢复为未读。阅读时长仅在阅读器前台、窗口聚焦且最近 90 秒内有操作时累计，失焦或长时间无操作会暂停。插件约每分钟保存一次时长，并在关闭阅读器时保存尚未写入的部分；按钮按整分钟显示，因此刚开始阅读时不会立即出现时长。阅读状态属于整篇文献：同一文献的多个 PDF 附件共享同一状态，多个窗口同时打开同一篇文献也不会重复计时。

文献列表最左侧以细色条区分状态：绿色表示已读，灰色表示未读，不额外显示“阅读”文字列或进度环。

列表右键菜单可直接标记已读或未读。

## AI 生成英文标签

在文献列表中右键单击一篇普通文献，选择“AI 生成标签”。插件会把论文标题和 Abstract 发送给所选服务，并返回英文标签建议。

选择该菜单后，插件才会发送标题和 Abstract。生成结果不会直接写入：你可以先勾选、删除或手动补充标签。点击“应用标签”时，确认框会留在标签预览窗口中；确认后插件才会替换该文献现有的手动标签，并保留 Zotero 自动标签。取消确认会继续保留预览窗口和当前编辑结果。

在“设置 → Zotero Puls”中可以配置：

- DeepSeek 或 OpenAI 服务；
- API Key 和模型；
- 最大标签数量；
- 自定义提示词。

DeepSeek 使用预设模型列表；OpenAI 可通过“获取可用模型”读取当前 API Key 可访问的文本模型。API Key 和其他设置仅保存在本机 Zotero 配置中。

## PDF 选区自动翻译

在 Zotero 内置 PDF 阅读器中选中文本后，原有的颜色、高亮和下划线菜单会照常显示，菜单下方会自动出现译文。可在“设置 → Zotero Puls → PDF 翻译”中关闭自动翻译、选择目标语言，并勾选翻译服务。

当前支持 Google Translate、火山网页翻译、腾讯 Transmart、知网翻译和爱词霸翻译。可在设置页用上下箭头调整服务优先级；插件仅按该顺序尝试已启用服务，当前服务失败后自动使用下一个，首次成功即停止。它们使用第三方网页接口，可能因外部服务调整而暂时或永久失效。

只有实际尝试的服务会收到当前选区文本。译文仅显示在选区菜单中，不会自动写入批注、笔记或文献字段。

## EasyScholar 期刊信息

在“设置 → Zotero Puls”中填写 EasyScholar Secret Key，并选择需要写入的信息字段。字段按以下类别整理：

- 常用分区；
- 指标与预警；
- 国内核心与收录；
- 国际学术排名；
- 高校与机构榜单；
- EasyScholar 自定义数据集。

将鼠标移到分类标题或具体字段上，可查看简短说明。所有配置会自动保存。

启用“新增文献时自动查询”后，插件不会在收到新增通知的瞬间查询，而是等待条目元数据连续约 3 秒不再变化后再开始。这样可让 Zotero 先完成 PDF 元数据识别、父条目创建和刊名补全。识别过程继续修改条目时，等待时间会自动重新计算；插件会在新增后的 60 秒内监听相关元数据变化，缺少刊名时每隔约 8 秒重试。即使已经查询成功，观察期内刊名、DOI 或会议信息再次被 Zotero 或元数据整理插件修改，也会使用新信息重新查询。也可以在文献列表中右键单击一篇普通文献，选择“更新 EasyScholar 信息”立即主动刷新。

### 与 Linter for Zotero 协同

如果同时使用 [Linter for Zotero](https://github.com/northword/zotero-format-metadata)，建议先让它完成 DOI、刊名、期刊缩写和条目格式整理，再由 Zotero Puls 查询分区。两者无需额外配置：Puls 会在新条目后的短暂观察期内检测相关元数据变化，并以整理后的信息重新查询。

只有刊名、会议名、论文集名、期刊缩写、DOI、URL 或 arXiv 存档信息的变化会触发重新查询；标题大小写、语言、页码等不影响查询名称的格式化不会额外请求 EasyScholar。

查询结果不会覆盖“其他”字段原有内容，而是在末尾维护一个独立的 `[EasyScholar] ... [/EasyScholar]` 区块。EasyScholar 接口限制为每秒最多 2 次请求。

查询时会综合使用 Zotero 已有元数据：期刊论文依次尝试刊名、期刊缩写和系列名；会议论文依次尝试会议名、论文集名、刊名和系列名。插件还会清理名称中的 `Proceedings of`、年份和卷号等常见附加文本，去重后最多尝试 5 个候选名称。该过程只辅助查询，不会修改 Zotero 原有的刊名或会议字段。

主动更新失败时，提示会区分“缺少可查询名称”“未找到期刊或会议”“已找到刊物但所选字段无数据”和接口错误，并列出本次实际尝试的名称。

### arXiv 正式发表版本

对于能够从存档字段、URL、DOI 或“其他”字段识别出 arXiv ID 的条目，右键菜单会显示“查找正式发表版本”。插件按以下顺序查找：

1. 从 arXiv 元数据读取正式 DOI 和期刊引用；
2. 使用 DOI 或论文标题、第一作者查询 Crossref；
3. Crossref 没有可信结果时使用 OpenAlex 作为备用来源。

结果必须达到可信匹配阈值，并排除 arXiv、CoRR 等预印本来源。主动查询会显示正式刊物或会议、DOI、年份、来源和匹配置信度；只有确认后才写回 Zotero。这里的“匹配置信度”是标题、第一作者和年份的一致性评分，并非经过统计验证的真实准确率。插件不会自动改变条目类型，当前条目不支持的刊物字段会保存到“其他”字段的 `[Published Version]` 区块。

“更新 EasyScholar 信息”也会联动此功能：本地刊名候选均未得到分区且当前条目是 arXiv 时，插件会尝试找到正式版本并以正式刊物名称查询 EasyScholar。这个自动过程只使用查询结果，不会修改原条目元数据。

### 文献列表分区列

插件会在 Zotero 文献列表中提供“EasyScholar 分区”列。若该列没有显示，可右键单击文献列表表头，在列选择器中启用它。

该列读取“其他”字段内已有的 EasyScholar 区块，不会因为显示列表而重复请求接口。列中只显示每个字段的结果值，不显示“JCR 分区”“影响因子”等字段名称；多个结果以独立的圆角标记排列。将鼠标移到单元格上可查看完整结果。

颜色用于快速区分等级：

- 红色：TOP、Q1、1 区、A、AA、A+ 等最高等级；
- 紫色：Q2、2 区、B 等第二等级；
- 蓝色：Q3、3 区、C 等第三等级；
- 绿色：Q4、4 区、D 等第四等级；
- 灰色：无法可靠换算为上述等级的收录状态或文本。

影响因子按数值分为四档：`≥10` 为红色、`≥5` 为紫色、`≥2` 为蓝色、`<2` 为绿色。颜色只是便于浏览的视觉分级，不代表插件对期刊质量作出的评价。

## 隐私说明

- 关系网数据仅在本机处理。
- 用户主动选择“AI 生成标签”后，插件会把当前论文的标题和 Abstract 发送给所选 AI 服务；标签预览中的确认只控制是否写入 Zotero。
- EasyScholar 功能会把期刊名或会议名发送给 EasyScholar。
- 正式版本识别会把 arXiv ID 发送给 arXiv，并把论文 DOI、标题和第一作者发送给 Crossref；必要时把标题发送给 OpenAlex。
- PDF 翻译会把当前选区文本依次发送给已启用且实际尝试的翻译服务，成功后停止继续请求。
- 阅读状态、已读时间和累计阅读秒数只保存在文献的“其他”字段中，不会发送到网络服务。
- API Key、Secret Key 和插件设置仅保存在本机 Zotero 配置中。

## 错误反馈

插件运行异常时会显示统一的错误编号、功能位置和具体信息，并把完整详情写入 Zotero 调试日志。反馈问题时请同时提供错误编号和对应日志；错误记录不会自动上传。
